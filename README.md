## 📌 Project Overview

**Amjad Portfolio** is a personal portfolio website showcasing the developer's profile, skills, and projects. Built with pure HTML, CSS, and JavaScript, it presents a professional online presence with a simple, elegant design.

---

## ✨ Key Features

- 👤 **Personal Profile** – About section with developer information
- 🖼️ **Visual Showcase** – Portfolio images highlighting work and experience
- 🔒 **Security Policy** – Includes a `SECURITY.md` file for responsible disclosure
- ⚡ **Lightweight** – No frameworks or build tools required

---
